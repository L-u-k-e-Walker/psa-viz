# psa-viz

Rendered PSA dynamics for a generic binary mixture A/B:

1. a single adsorption column running a 4-step Skarstrom cycle at cyclic steady state;
2. a zoom on two particles comparing equilibrium and kinetic selectivity.

A is the heavy component (extract); B is the light component (raffinate).
All inputs are illustrative assumptions, not measured data (see docs/INPUTS.md).
Status and plan: docs/MISSION.md. Work in progress.
